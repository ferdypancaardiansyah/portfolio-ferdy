UI Design Aplikasi MenuMakanan

Tentang Project

Project ini berfokus pada perancangan antarmuka aplikasi menu makanan yang dibuat untuk memberikan pengalaman pengguna yang nyaman, tampilan modern, serta navigasi yang mudah digunakan pada perangkat mobile.


Fitur Utama

  • Tampilan Daftar Menu Makanan
  • Halaman Detail Produk
  • Desain Mobile Friendly
  • Layout Modern dan Bersih
  • Navigasi yang Mudah Digunakan

Teknologi

UI Design UX Design Mobile App

Apa yang Saya Pelajari

Melalui project ini saya mempelajari prinsip dasar desain antarmuka pengguna (UI), pengaturan layout aplikasi mobile, pemilihan warna, ikon, serta pembuatan desain yang lebih menarik dan mudah digunakan.
